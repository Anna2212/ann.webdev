# annwebdev.com

Персональний сайт Анни Медвідь. Astro, статична збірка, хостинг на Netlify.

## Запуск локально

Потрібен Node 20 або новіший. Перевірити: `node -v`

```bash
npm install     # один раз
npm run dev     # відкриється http://localhost:4321
```

Сторінка оновлюється сама, щойно зберігаєш файл.

```bash
npm run build   # зібрати в dist/
npm run preview # подивитись зібрану версію
```

## Деплой

Netlify збирає сайт сам при кожному пуші в основну гілку. Налаштування вже
лежать у `netlify.toml`, у панелі нічого вписувати не треба.

Кожна гілка отримує свою прев'ю-адресу — зручно показати клієнту або перевірити
правку до того, як вона потрапить на бойовий сайт.

## Структура

```
src/
  data/site.ts        Контакти, меню, тексти кнопок — єдине джерело правди
  layouts/Base.astro  Шаблон сторінки: head, мета-теги, schema, шапка, футер
  components/         Logo, Header, Footer
  pages/              Кожен файл = сторінка сайту
  styles/global.css   Дизайн-токени і базові стилі
public/               Файли, що копіюються як є: фавікон, robots.txt
```

## Де що міняти

**Контакти, телефон, пошта, посилання на соцмережі** — `src/data/site.ts`.
Змінюєш в одному місці, міняється на всьому сайті.

**Пункти меню** — там само, масив `NAV`. Порядок у масиві = порядок у меню.

**Кольори, розміри шрифтів, відступи** — `src/styles/global.css`, блок `:root`
на початку файлу. Це всі токени з брендбуку.

**Текст на сторінці** — відповідний файл у `src/pages/`. Верхня частина файлу
між `---` це налаштування сторінки, нижня — сам вміст.

## Дизайн-токени

| Змінна | Значення | Де живе |
|---|---|---|
| `--paper` | `#FBF8F3` | Базовий фон сторінки |
| `--cream` | `#F1E9DC` | Фон секцій, що чергуються |
| `--cream-dark` | `#E7DCC8` | Обведення карток, роздільники |
| `--ink` | `#241C16` | Основний текст, футер |
| `--ink-soft` | `#5B4F44` | Вторинний текст |
| `--terracotta` | `#C6673B` | Акцентне слово, знак у лого |
| `--terracotta-deep` | `#A8522C` | Кнопки й посилання |
| `--wine` | `#5A2A2E` | Фон блока із заявкою |
| `--sage` | `#6E7154` | Акцент на сторінці «Про мене» |

Два відтінки теракоти — не помилка. `--terracotta` красивіший, але його контраст
з кремовим фоном 3.2:1, і дрібний текст ним читати важко. `--terracotta-deep`
дає 5.3:1 і проходить норму доступності, тому всі кнопки й посилання на ньому.

## Шрифти

Montserrat, Playfair Display Italic і Caveat лежать у проєкті локально, через
пакети `@fontsource`. Зовнішніх запитів до Google Fonts немає — це швидше і не
залежить від сторонніх серверів.

Playfair Display використовується **тільки** в заголовках від 32px, одне-два
слова через клас `.accent`. У дрібному тексті курсивна антиква мажеться.

## Класи, які знадобляться

| Клас | Що робить |
|---|---|
| `.container` | Обмежує ширину до 1200px і додає бічні поля |
| `.section` | Вертикальні відступи секції |
| `.section--paper` / `--cream` / `--ink` / `--wine` | Фон секції |
| `.accent` | Акцентне слово Playfair Italic у заголовку |
| `.kicker` | Дрібний надзаголовок капсом |
| `.lead` | Великий вступний абзац |
| `.hand` | Рукописний текст Caveat |
| `.card` | Картка з обведенням |
| `.badge-num` | Кругла нумерована плашка 01 / 02 / 03 |
| `.btn .btn--primary` / `--secondary` / `--light` | Кнопки |
| `.grid .grid--2` / `--3` / `--4` | Сітки |
| `.reveal` | Блок з'явиться при скролі |

## Доступність

- Посилання «Перейти до вмісту» для клавіатури, з'являється при фокусі
- Видима рамка фокуса на всіх інтерактивних елементах
- `prefers-reduced-motion` вимикає всі анімації для тих, хто про це попросив
  у налаштуваннях системи
- Мінімальна область натискання 44×44 пікселі
